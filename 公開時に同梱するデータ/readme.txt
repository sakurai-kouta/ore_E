■どんなゲーム？

ジャンル：お絵描き対戦バトル

相手より強そうなイラストを描こう！
あなたの描いたイラストを元に、AIが勝手にステータスを決めてくれます。
戦場の環境(お題)に沿ったイラストを描くとより強くなります。
また、相手に有利な属性のイラストを描くとさらに強くなります。

■操作方法
マウス左クリック：
	いたるところのボタンを押す。
	（お絵描き中の場合）選択中のツールでお絵描きする。
マウス右クリック：
	（お絵描き中の場合）色を抽出する。
	

■攻略のヒント
・まずはストーリーモードを遊んでみよう！
　雰囲気が掴めたら、ランダムマッチ/合言葉マッチで対戦に挑もう！

・自分の提出した環境(お題)だけでなく、相手の提出した環境も確認しよう！
　両方に当てはまるキャラを描ければ、さらにステータスアップ！

・キャラクターっぽくない絵（塗りつぶしただけ、記号のみ、など）はステータス大幅ダウン…。
　魅力的なイラストを描こう！

・AIは、イラストの巧拙をあまりちゃんと見てません。
　イラストが苦手でも、自分なりに強そうなキャラを描ければそれでOKです！
